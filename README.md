# 飞翔小鸟 - 冒险版 🐦

一款功能丰富的 Java Swing 飞翔小鸟游戏，包含20个关卡、多种皮肤系统、成就系统等丰富内容。

## 🎮 游戏简介

飞翔小鸟冒险版是一款经典的飞翔小鸟游戏的增强版本，拥有丰富的游戏内容和精美的视觉效果。玩家控制小鸟在空中飞翔，躲避各种障碍物，收集金币和道具，挑战不同难度的关卡。

### 核心特色
- 🎯 **20个精心设计的关卡** - 难度逐渐增加，挑战你的反应能力
- 🎨 **丰富的皮肤系统** - 小鸟皮肤、障碍物皮肤、游戏场景
- 🏆 **成就系统** - 15种成就等你来解锁
- 🎁 **道具系统** - 4种强力道具助你闯关
- 💰 **经济系统** - 收集金币，解锁更多内容
- 📊 **排行榜** - 记录你的最高分
- 📖 **新手教程系统** - 首次启动自动引导，轻松上手
- 🎵 **背景音乐系统** - 菜单/游戏/结束场景独立配乐，支持淡入淡出
- ✨ **界面动画优化** - 按钮悬停高亮、脉冲弹跳动画效果
- 🎨 **UI美化** - 统一配色方案、样式化圆角按钮、半透明遮罩
- 🔊 **音效增强** - 金币音效变体随机播放、按钮悬停音效、页面切换音效

## 🚀 快速开始

### 系统要求
- **Java 版本**：JDK 8 或更高版本
- **操作系统**：Windows / macOS / Linux
- **内存**：至少 100MB 可用内存
- **屏幕分辨率**：建议 800x600 以上

### 运行方式

#### 方式一：直接运行 JAR 文件（推荐）
```bash
# 双击运行
飞翔小鸟冒险版.jar

# 或者命令行运行
java -jar 飞翔小鸟冒险版.jar
```

#### 方式二：从源码运行
```bash
# 进入项目目录
cd 飞翔小鸟_冒险版

# 编译源码
javac -encoding UTF-8 cn/edu/huse/game/*.java

# 运行游戏
java cn.edu.huse.game.BirdGame
```

#### 方式三：使用打包脚本
```bash
# 双击运行 build.bat（Windows）
# 或者手动执行打包流程
```

## 🎨 功能详细介绍

### 1. 关卡系统 🏁

游戏包含 **20个精心设计的关卡**，每个关卡都有独特的挑战：

| 关卡 | 难度 | 特点 |
|------|------|------|
| 1-5 | ⭐ | 新手入门，障碍物间距大，速度慢 |
| 6-10 | ⭐⭐ | 进阶挑战，障碍物间距缩小 |
| 11-15 | ⭐⭐⭐ | 高手挑战，速度加快，间隙更小 |
| 16-20 | ⭐⭐⭐⭐ | 极限挑战，高速高难度 |

**关卡特点：**
- 每个关卡需要通过 **10个障碍物** 才能通关
- 通关后自动解锁下一关卡
- 可以随时选择已解锁的关卡进行游戏
- 每个关卡都有独立的得分记录

### 2. 皮肤系统 🎨

#### 小鸟皮肤
游戏提供 **4种独特的小鸟皮肤**，每种都有独特的外观和动画：

| 皮肤名称 | 价格 | 描述 |
|----------|------|------|
| 经典UFO | 免费 | 默认皮肤，UFO造型 |
| 愤怒小鸟 | 100 金币 | 红色愤怒小鸟 |
| 蜜蜂 | 200 金币 | 勤劳的小蜜蜂 |
| 幽灵 | 300 金币 | 神秘幽灵 |

**皮肤特点：**
- 每种皮肤有 **4帧动画**
- 装备后立即生效
- 可以随时切换已解锁的皮肤

#### 障碍物皮肤
游戏提供 **5种障碍物皮肤**，改变障碍物的外观：

| 皮肤名称 | 价格 | 描述 |
|----------|------|------|
| 太空站 | 免费 | 经典太空机械方块样式 |
| 竹林 | 200 金币 | 绿色翠竹造型 |
| 冰川 | 300 金币 | 淡蓝冰雪方块、带冰花特效 |
| 水晶 | 400 金币 | 紫粉渐变的魔幻水晶方块 |
| 木桩 | 500 金币 | 原木纹理木墩样式 |

**皮肤特点：**
- 动态脉冲发光效果
- 科技感十足的视觉效果
- 不影响游戏难度

#### 游戏场景
游戏提供 **5种不同的游戏场景**：

| 场景名称 | 价格 | 描述 |
|----------|------|------|
| 星空 | 免费 | 默认星空背景 |
| 深海 | 200 金币 | 深海世界背景 |
| 森林 | 300 金币 | 神秘森林背景 |
| 沙漠 | 400 金币 | 沙漠绿洲背景 |
| 火山 | 500 金币 | 火山熔岩背景 |

### 3. 道具系统 🎁

游戏中有 **4种强力道具**，帮助你更好地通关：

#### ⭐ 无敌星星
- **效果**：短暂进入无敌状态，无视所有碰撞
- **持续时间**：约 3 秒
- **使用技巧**：在密集障碍物区域使用

#### 🧲 磁铁
- **效果**：自动吸附附近的金币
- **持续时间**：约 5 秒
- **使用技巧**：在金币密集区域使用，最大化收益

#### 🐌 减速器
- **效果**：降低游戏速度 50%
- **持续时间**：约 4 秒
- **使用技巧**：在高难度区域使用，更容易躲避障碍物

#### 🛡️ 护盾
- **效果**：抵挡一次碰撞（包括地面和障碍物）
- **持续时间**：直到被消耗
- **使用技巧**：在危险区域提前激活

**道具特点：**
- 道具随机出现在游戏中
- 收集后立即生效
- 可以同时拥有多种道具效果
- 道具状态会在UI上显示剩余时间

#### 收集成就

- 成就进度会保存到存档

### 5. 无限模式 ♾️

**解锁条件**：通关所有20个关卡

**模式特点：**
- 无尽挑战，没有终点
- 难度逐渐增加（速度加快、间隙缩小）
- 记录综合得分（障碍物×10 + 金币×5）
- 独立的排行榜
- 可以随时暂停

**计分规则：**
- 每通过一个障碍物：+10分
- 每收集一个金币：+5分
- 综合得分 = 障碍物×10 + 金币×5

### 6. 排行榜系统 📊

游戏记录以下数据：
- **普通模式最高分**：每个关卡的最高分
- **无限模式最高分**：无限模式的综合得分
- **TOP 5 排行榜**：历史最高分前5名

**排行榜特点：**
- 自动保存最高分
- 支持无限模式独立排行
- 显示排名和分数

### 7. 存档系统 💾

游戏支持 **3个存档槽位**，可以保存和加载游戏进度：

#### 存档内容
- 游戏进度（关卡、金币、得分）
- 皮肤装备状态
- 成就进度
- 排行榜数据

#### 存档操作
- **保存**：将当前进度保存到指定槽位
- **加载**：从指定槽位恢复游戏进度
- **删除**：删除指定槽位的存档
- **重命名**：为存档添加自定义名称
- **导出**：将存档导出为JSON格式
- **导入**：从JSON格式导入存档

**存档位置**：`~/.bird_adventure/`（用户目录下）

### 8. 设置系统 ⚙️

游戏设置界面提供以下功能：

#### 音量控制
- **音效音量**：调节游戏音效的音量（0-100%）
- 设置会自动保存，下次启动生效

#### 存档管理
- 查看3个存档槽位的状态
- 执行保存、加载、删除、重命名操作
- 导入导出存档功能

#### 数据管理
- **重置金币**：将金币数量重置为0
- **恢复出厂设置**：删除所有存档和设置，恢复默认状态

### 9. 作弊模式 🎮

**开启方式**：在主菜单右下角点击"C"按钮

**作弊功能：**
- 获得 99999 金币
- 解锁所有关卡
- 解锁所有皮肤（小鸟、障碍物、场景）
- 解锁所有成就

**关闭作弊**：再次点击"C"按钮，金币恢复到作弊前的数量

**作弊控制台**（按 ` 键打开）：
- `money`：获得 99999 金币
- `health`：生命值设为 999
- `unlock`：解锁所有内容
- `god`：开启/关闭无敌模式
- `clear`：清除所有作弊效果

## 🐛 问题排查

### 常见问题

#### 1. 游戏无法启动
**可能原因**：
- 未安装 Java 运行环境
- Java 版本过低

**解决方法**：
```bash
# 检查 Java 版本
java -version

# 如果未安装，请下载安装 JDK 8+
# 推荐：https://www.oracle.com/java/technologies/downloads/
```

#### 2. 游戏运行卡顿
**可能原因**：
- 系统资源不足
- 后台程序占用过多资源

**解决方法**：
- 关闭不必要的后台程序
- 降低游戏分辨率（修改 GameConfig.java）

#### 3. 音效没有声音
**可能原因**：
- 系统音量静音
- 音效文件缺失

**解决方法**：
- 检查系统音量设置
- 重新下载游戏文件

#### 4. 存档丢失
**可能原因**：
- 删除了用户目录下的存档文件
- 系统清理工具误删

**解决方法**：
- 存档位置：`~/.bird_adventure/`
- 建议定期导出存档备份
