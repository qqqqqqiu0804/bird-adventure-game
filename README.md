# 飞翔小鸟 - 冒险版

## 游戏简介
这是一款Java Swing开发的飞翔小鸟冒险游戏，包含丰富的游戏内容：
- 20个关卡，难度逐渐增加
- 多种皮肤和场景可解锁
- 无限模式挑战最高分
- 成就系统和排行榜
- 道具系统（无敌、磁铁、减速、护盾）

## 运行方法

### 方法一：直接运行JAR文件（推荐）
1. 双击 `飞翔小鸟冒险版.jar` 文件即可运行
2. 如果无法运行，请确保已安装Java运行环境（JRE 8或更高版本）

### 方法二：命令行运行
```bash
java -jar 飞翔小鸟冒险版.jar
```

### 方法三：从源码运行
```bash
# 编译
javac -encoding UTF-8 cn/edu/huse/game/*.java

# 运行
java cn.edu.huse.game.BirdGame
```

## 打包方法
1. 双击运行 `build.bat` 脚本
2. 等待编译和打包完成
3. 生成的 `飞翔小鸟冒险版.jar` 文件可以直接分享给其他人

## 游戏操作
- **鼠标点击/空格键**：小鸟上升
- **P键**：暂停游戏
- **C键**：作弊模式（主菜单右下角）

## 作弊模式
在主菜单右下角点击"C"按钮开启作弊模式：
- 自动解锁所有关卡、皮肤、场景
- 获得99999金币
- 再次点击关闭作弊模式，金币恢复

## 系统要求
- Java 8 或更高版本
- Windows/Mac/Linux 操作系统
- 至少 100MB 可用内存

## 开发信息
- 开发语言：Java
- 图形框架：Java Swing
- 开发环境：JDK 8+

## 注意事项
1. 首次运行会在用户目录创建存档文件：`~/.bird_adventure/`
2. 游戏进度会自动保存
3. 如果遇到问题，可以删除存档文件重新开始
